# KB (Knowledge Base)

This folder is the shared, practical knowledge base for the Mao Team.

Note: `KB/` is the canonical location. The lowercase `kb/` folder may exist for legacy drafts; avoid adding new docs there.

Goals:
- Turn learnings into actionable, repeatable playbooks.
- Keep agent workspaces aligned without mixing chat history.

How to contribute:
1) Write a Learning Packet using `KB/LEARNING_PACKET_TEMPLATE.md`.
2) Post a short delivery summary to `#delivery-hall` using `KB/DELIVERY_HALL_TEMPLATE.md` and @Mimi.
3) If it changes how we operate, update `RULES.md` / a playbook.
4) Keep it concrete: steps, commands, config snippets, do/don't.
