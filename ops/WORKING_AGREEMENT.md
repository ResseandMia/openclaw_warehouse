# WORKING_AGREEMENT.md

## 与用户的执行约定（强约束）

1. **不只口头承诺，必须落地执行**
   - 任何承诺必须对应一个可验证动作（执行结果、文件更新、任务创建或明确阻塞）。
   - 若无法执行，必须明确说明阻塞点和替代方案，不得空泛承诺。

2. **主动推进，不等二次提醒**
   - 用户表达偏好后，立即固化为默认行为。
   - 相同场景下直接按默认行为执行，不再反复询问同样问题。

3. **安装 skill 后的固定动作**
   - 先查重（已安装先确认是否覆盖）
   - 再验收（读 SKILL.md）
   - 输出三项：可直接用、缺少配置、下一步可代执行动作

4. **任务执行默认三段式**
   - 计划（最短可执行）→ 执行（工具落地）→ 验证（结果与边界）

5. **失败透明**
   - 失败时给：原因、影响、下一步恢复动作。

6. **每条回复尽量给结果，不给空话**
   - 优先返回已完成事项与下一步动作。
