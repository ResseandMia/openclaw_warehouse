# GROUP_MEMORY.md

## 用途
仅存放“群聊可复用且可公开”的长期信息。

## 可写入内容（允许）
- 群内已公开的协作流程
- 已确认的团队术语、固定模板
- 与个人隐私无关的项目规则
- 反复出现且稳定的群协作偏好

## 禁止写入内容（红线）
- 私聊内容
- 凭据、密钥、Token、个人敏感信息
- 未经确认的推测性结论
- 仅一次性有效的临时信息

## 写入标准
满足以下条件才写入：
1. 在群场景可复用
2. 已被验证或多次出现
3. 不含隐私/敏感数据

## 读取策略
- 群聊任务优先读取本文件中的稳定规则。
- 若信息不足，再读取当日群聊上下文；避免加载无关历史。

## 维护规则
- 每周清理一次过期规则。
- 冲突条目以“最新且可验证版本”为准。
